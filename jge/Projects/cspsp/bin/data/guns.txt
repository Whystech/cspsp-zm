# HOW TO ADD A WEAPON
# The first line is the number of weapon records loaded. Change 32 to 33
# when adding ID 32, to 34 when adding ID 33, and so on (maximum 64).
# Insert every new weapon record ABOVE these notes. Do not put blank or
# comment lines between records included by the count.
# Keep IDs sequential and equal to the record position: 0, 1, 2, ... 63.
# The ID selects the matching 32x32 cell in guns.PNG and gunsground.png.
# With the 128-pixel-wide sheets, each row contains four IDs.
#
# RECORD FORMAT (18 whitespace-separated values)
# id damage delay spread clip numclips reloaddelay walkingspeed bulletspeed viewangle cost type firemode pellets scope category teams name
#
# id             Weapon ID, matching its record position and sprite cell.
# damage         Base damage per bullet (actual bullet damage varies slightly).
# delay          Time between shots in milliseconds; lower is faster.
# spread         Weapon spread/recoil angle in radians; lower is more accurate.
# clip           Rounds loaded in one magazine.
# numclips       Total magazines supplied, including the initially loaded one.
# reloaddelay    Reload duration in milliseconds.
# walkingspeed   Movement-speed multiplier while this weapon is equipped.
# bulletspeed    Projectile-speed multiplier; normal firearms usually use 1.0.
# viewangle      View-cone half-angle in radians; 0.0 disables the cone effect.
# cost           Buy-menu price.
# type           Inventory slot: 0=PRIMARY, 1=SECONDARY, 2=KNIFE, 3=GRENADE.
# firemode       Trigger mode: 0=SEMI (one shot per press), 1=AUTO (hold to fire).
# pellets        Projectiles per shot: 1=normal; values such as 4 or 6=shotgun.
# scope          Camera scope: 0=NONE, 1=LOW, 2=MEDIUM, 3=HIGH.
# category       Buy menu: 0=HIDDEN, 1=PISTOLS, 2=SHOTGUNS, 3=SMG,
#                4=RIFLES, 5=MACHINEGUNS, 6=EQUIPMENT.
# teams          Buy availability: 0=NONE, 1=T only, 2=CT only, 3=BOTH.
# name           Internal name, maximum 14 characters and no spaces.
#                Normal guns load sfx/NAME.wav and sfx/NAMEreload.wav.
#                Missing files fall back to AK47 sounds for primary weapons,
#                GLOCK sounds for secondary weapons, KNIFE sounds for knives,
#                and the pin-pull sound for grenades.
#
