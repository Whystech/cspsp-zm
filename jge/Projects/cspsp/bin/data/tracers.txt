# Client-only tracer overrides keyed by gun ID.
# Missing IDs use the original orange line tracer.
# Format: gunId style red green blue alpha length width
# Styles: none, line, laser, dot, dashed, beam, plasma, bolt,
# comet, pulse, rail, spark, needle, twin, zigzag, flare, streak, slug
#
# COLUMN REFERENCE
# gunId  Weapon ID from the first column of guns.txt. Valid range: 0-127.
# style  Shape used to draw the tracer. Valid names are listed above.
# red    Amount of red in the tracer color. Range: 0-255.
# green  Amount of green in the tracer color. Range: 0-255.
# blue   Amount of blue in the tracer color. Range: 0-255.
# alpha  Tracer opacity/intensity. 0 is invisible; 255 is fully visible.
# length Trail length in world pixels. 0 uses the original speed-scaled length.
# width  Line/projectile thickness. Must be greater than 0; decimals are valid.
#
# RGB examples: 255 0 0 = red, 0 255 0 = green, 0 0 255 = blue,
# 255 255 255 = white, and 255 165 0 = the original orange.
# The active test assignments at the bottom give every current weapon a style.
#
# HOW TO ATTACH A TRACER TO A WEAPON
# 1. Find the weapon ID in data/guns.txt (the first value in its row).
# 2. Add one tracer row below using that same ID.
# 3. Do not start the row with #; # makes a row a comment and disables it.
# 4. Restart the game after saving this file.
# Example: AK47 is ID 18 in guns.txt. This active row would give it a red laser:
# 18 laser 255 30 30 255 64.0 1.0
# Only one active row should be used per gun ID. Guns without a row keep the
# original orange tracer. This file affects client graphics only, not damage,
# bullet speed, collision, server behavior, or network compatibility.
#
# Examples:
# 1 dot 255 210 120 255 0.0 1.5        pistol projectile point
# 17 line 255 180 40 225 28.0 1.0      standard rifle tracer
# 18 dashed 255 200 70 230 72.0 1.5    machine-gun tracer
# 23 laser 255 30 30 255 64.0 1.0      thin laser
# 36 beam 70 180 255 240 80.0 1.5      energy beam with white core
# 37 plasma 80 255 190 220 48.0 1.5    glowing plasma projectile
# 38 bolt 210 180 120 255 24.0 1.5     arrow or crossbow bolt
# 39 comet 100 220 255 230 60.0 1.5    bright head with a tapered tail
# 40 pulse 180 80 255 230 72.0 1.5     five fading energy points
# 41 rail 80 200 255 245 90.0 1.0      twin rails with a white center
# 42 spark 255 240 100 255 24.0 1.0    short trail with a cross-shaped tip
# 43 needle 230 230 255 255 36.0 1.0   very thin, short projectile streak
# 44 twin 255 80 80 230 56.0 1.0       two parallel tracer lines
# 45 zigzag 120 200 255 230 64.0 1.0   electric zigzag path
# 46 flare 255 120 40 240 32.0 1.0     bright star-shaped projectile tip
# 47 streak 255 220 140 230 72.0 1.0  long dim tail with a bright front
# 48 slug 190 190 190 255 28.0 1.5    short, thick physical projectile
# 25 none 255 255 255 0 0.0 1.0        hidden tracer
